## Finding Title

Unchecked User Authentication for Password Update

## Risk

High

## Evidence

The `update_password()` function does not verify whether the authenticated user is authorized to change another user's password.

## Exploit Scenario

1. An attacker obtains a valid token.
2. The attacker submits a password change request targeting another user.
3. The password update succeeds because object-level authorization is not enforced.

## AI Recommended Remediation

The model recommended:

- Extracting the authenticated user from the validated token.
- Comparing the authenticated user against the target username.
- Allowing exceptions only for authorized administrative users.
- Returning HTTP 403 when authorization checks fail.

### AI-Generated Example Fix

```python
authenticated_user = resp['sub']

if not is_admin and username != authenticated_user:
    return Response(
        error_message_helper("Unauthorized update of password"),
        403,
        mimetype="application/json"
    )
```

## Human Validation

Status: Confirmed

Human review verified that the endpoint contains a Broken Access Control / Broken Object Level Authorization (BOLA) vulnerability.
